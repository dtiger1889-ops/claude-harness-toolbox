# Correct the previous work

1. Re-read the user's actual request and identify the concrete failure in one line. Investigate disputed facts; do not defend the previous answer or invent a failure to agree.
2. Complete the correction within the authorized scope. Read sources or artifacts first when needed. Give the corrected result, not a plan to fix it.
3. If the intended correction remains unclear after reviewing the context, ask one focused question and continue any independent work.
4. Record reusable findings in the owning project's existing lesson or lapse record. Separate an incident from a standing preference: do not turn a one-off correction into a new permanent rule without evidence of that intent.

Keep the reply short. If prevention requires changing a workflow, use prevent; if the issue is disputed claims, use prove.
